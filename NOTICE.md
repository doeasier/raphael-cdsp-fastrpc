# NOTICE

This repository is a **research record** (self-archive) produced on 2026-11-06 for the
Redmi K20 Pro / Mi 9T Pro (`raphael`, SM8150) mainline-Linux cDSP work.

## Not included: vendor binaries

No Qualcomm / Xiaomi firmware blob is redistributed here. In particular the following are
**intentionally absent**: `cdsp.mdt`, `cdsp.bXX`, `cdsp.mbn`, `cdspr.jsn`,
`fastrpc_shell_3`, `fastrpc_shell_unsigned_3`, `lib*_skel.so`, `NON-HLOS.bin`,
`firmware-xiaomi-raphael.deb`, the `deploy-bundle.tar.gz`, and all compiled `.so` files.
`.gitignore` enforces this. Their copyright and redistribution terms belong to their
respective owners; obtain them from the official MIUI package
(China Stable `V12.5.6.0.RFKCNXM`, 2021-07-30) or from your own device, and verify against
the hashes in `docs/04-FIRMWARE-MANIFEST.json`.

The file names, build strings, ELF program-header values and SHA-256 digests recorded here
are factual observations, not copies of the binaries.

## Included content

- `docs/`, `evidence/`, `README.md`: original notes, logs and analysis written for this project.
- `tools/`, `example/`: original scripts and the hand-written HVX sample. Parts of
  `example/gen/*` were generated by the QAIC IDL compiler and remain subject to the terms of
  that toolchain. `tools/pr319.diff` is a small upstream patch excerpt kept as a research
  reference with attribution.
- The Linux kernel source (`drivers/misc/fastrpc.c`, GPL-2.0) is **not** redistributed here;
  the research log references it by path and line number only.

## Redaction

Device SSH passwords, the private WLAN address, local Windows user/workspace paths and any
credential material were replaced with placeholders before archiving. The scripts in
`tools/` therefore contain `<REDACTED>` where a password used to be and are **not
run as-is**; supply your own credentials locally.
